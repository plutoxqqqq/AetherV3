## Interface

AetherV3 ships with a single asset-free interface featuring live module search,
a command palette, configurable themes and scaling, profile import/export,
desktop and touch controls, notifications, an enabled-module array list, and a
performance watermark.

The runtime is fully standalone: the loader, shared runtime object, module
registry, lifecycle management, configuration system, notifications, overlays,
and GUI controls are all provided by AetherV3 itself. No external client
framework is required or referenced.

- Press **Right Shift** to show or hide the interface.
- Press **/** to search modules.
- Press **Ctrl + P** to open the command palette.
